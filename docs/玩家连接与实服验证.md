# 玩家连接与实服验证

更新日期：2026 年 10 月 28 日。适用版本：CraftHome v0.1 基础控制版。

## 现在如何进入游戏

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| WebUI | `http://47.104.68.190:5080` | 服主管理网页，用当前面板密码登录 |
| Minecraft Java | `47.104.68.190:25565` | 在游戏客户端添加服务器 |
| 管理引擎 | `127.0.0.1:23333` | 服务器内部使用，不给玩家连接 |

服务器运行 **Paper / Minecraft Java 1.21.11**。在 PCL 等启动器中准备对应版本；如使用离线账号，用户名设为 **`JeRyan`**，大小写保持一致。启动游戏后打开“多人游戏 → 添加服务器”，填写上面的 Minecraft 地址并连接。

当前允许离线账号，仍启用白名单；已添加 `JeRyan`，其他玩家名需要另行加入。PCL 是启动器，是否正版验证取决于服务器和账号模式，不能仅根据启动器名称判断。

离线模式下账号按名字识别。白名单不能阻止冒用已允许的名字，当前尚未安装游戏内密码验证插件，也没有白名单管理 WebUI。

## 为什么之前显示 localhost

之前的 `127.0.0.1:25566（SSH 隧道）` 是隔离测试入口，游戏只监听服务器本机；其他玩家无法用该地址直接进入。现在已修改实际游戏监听与查询端口，而不仅仅替换界面文字：

- `server-ip=0.0.0.0`、`server-port=25565`。
- `online-mode=false`、`enforce-secure-profile=false`。
- `white-list=true`、`enforce-whitelist=true`。
- `JeRyan` 使用离线模式对应 UUID 加入白名单。
- MCSManager 查询地址为服务器本机 `127.0.0.1:25565`。
- UFW 允许 TCP 25565，已从开发电脑通过公网实际连入。

原 `/opt/minecraft` 服务仍停止，世界与插件保留。新实例仍在 `/opt/crafthome-test/game`。修改前的游戏配置和白名单已备份到服务器 root 的私有目录，没有放进 Git。原服务仍保留开机自启设置；重启机器后若原服占用 25565，应先确认运行的是哪个实例，避免同时使用同一端口。

这证明公网网络、离线登录、白名单和进入世界的协议流程正常；没有操作 PCL 图形界面，也没有测试长时间游玩、多人承载或模组兼容性。服务器仅约 1.6 GiB 物理内存，当前 Java 堆上限 512 MiB，仍属于基础功能测试配置。

## 当前 UI 的能力范围

可以登录管理台，配置已有 MCSManager 实例，查看状态／内存／日志并执行启动、正常停止和重启。首页已明确标注“玩家连接地址”，设置页也说明它只更新显示。

实例自动创建、游戏版本切换、Mod／插件安装、游戏内角色和领地管理仍未实现。客户端仍需单独安装 Minecraft Java，并匹配服务器版本。
