# CraftHome 公网访问与 SSH 凭据说明

更新日期：2026 年 10 月 28 日。

## SSH 使用的是哪种凭据

本次 SSH 登录使用 `root` 用户及用户提供的登录密码，没有配置客户端 SSH 登录私钥。SSH 协议会自动协商加密连接使用的会话密钥，用户无需手动填写这个密钥。

三种凭据用途不同：

| 凭据 | 用途 |
| --- | --- |
| root 的 SSH 登录密码 | 登录 Linux 服务器、建立隧道、执行部署操作 |
| CraftHome 的服主密码 | 登录 WebUI，账户为 `owner@crafthome.local` |
| MCSManager API Key | CraftHome 后端访问管理引擎，不需要拿它登录 SSH 或 WebUI |

SSH 的 `known_hosts` 保存服务器主机公钥信息，用来识别服务器身份；它不是登录私钥。WebUI 首次登录信息保存在本机 `D:\MCstart\.local\server-first-login.txt`。修改密码后，这个文件不会自动更新，应使用当前密码。本说明不包含任何密码或 API Key。

## 恢复只通过 SSH 访问

可以保留配置文件作备份，改成 systemd 不识别的后缀，然后重启控制台：

```bash
sudo mv /etc/systemd/system/crafthome.service.d/public-access.conf /etc/systemd/system/crafthome.service.d/public-access.conf.disabled
sudo systemctl daemon-reload
sudo systemctl restart crafthome
sudo ufw delete allow 5080/tcp
```

原服务文件仍定义 `127.0.0.1:5080`，因此撤销该覆盖配置后将恢复回环监听。
