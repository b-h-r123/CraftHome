# CraftHome v0.2 测试报告

测试日期为 2026 年 11 月 7 日。测试环境为 Ubuntu 24.04 x86_64、Java 21、MCSManager Web 10.22.0 / Daemon 4.19.3。使用独立 Paper 1.21.11 测试实例，原有世界和实例保留。

| 项目 | 已验证的结果 |
|---|---|
| .NET 自动测试 | 36 项通过。覆盖 Owner 访问限制、EULA、错误哈希、低内存、端口冲突、离线 UUID、上传、新配置文件写入和启动状态查询重试。 |
| 已有环境升级 | `--check` 只读检测通过。`--upgrade` 备份程序并保留已有账户、MCSManager 和控制台入口。 |
| 浏览器登录和环境检测 | 已使用原 Owner 登录公网 WebUI，读取 Java、内存、磁盘和 Paper 官方版本列表。 |
| EULA 拦截 | 浏览器未勾选 EULA 时拒绝创建。确认后继续。 |
| 新建和配置 | WebUI 创建独立实例，官方 Paper 1.21.11 构建 132 的 `server.jar` 校验通过，写入游戏属性、白名单和 EULA。 |
| 干净 Ubuntu 首次安装 | 通过。自动安装依赖和引擎，验证加密保存连接并清理一次性交接文件。已有系统默认 Java 17 时，向导能选择单独安装的 Java 21。 |
| 干净 Ubuntu 开服、查询与停服 | 通过。浏览器从空实例创建 Paper 1.21.11（构建 132），1 GiB Java 堆，约 1 分钟后游戏查询响应，随后正常停止。390 px 手机宽度无横向溢出，浏览器未记录运行错误。 |
| 用户实服首次启动 | Java 启动和端口监听通过。主机约有 1.6 GiB 内存，使用 512 MiB Java 堆，生成世界时出现连接超时。健康接口曾恢复响应，SSH 和浏览器登录仍间歇超时，实服游戏就绪、正常停服、切回旧实例与最终构建部署尚未确认。 |

实服上的临时测试端口与原游戏端口分开，公网安全组未为临时端口新增规则。浏览器测试核对管理和本机游戏查询流程，公网联机需独立验证。建议以测试记录中明确通过的项目为准。

干净环境的验收记录包含浏览器桌面和手机截图、结构化结果及发行包。可以在运行页面的 `Artifacts` 区域下载 `wizard-test-evidence`。 [GitHub Actions 通过记录](https://github.com/b-h-r123/CraftHome/actions/runs/42366756631)
