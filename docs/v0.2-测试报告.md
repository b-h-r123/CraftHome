# CraftHome v0.2 测试报告

测试环境为 Ubuntu 24.04 x86_64、Java 21、MCSManager Web 10.22.0 / Daemon 4.19.3。使用独立 Paper 1.21.11 测试实例，原有世界和实例保留。

| 项目 | 已验证的结果 |
|---|---|
| .NET 自动测试 | 35 项通过。覆盖 Owner 访问限制、EULA、错误哈希、低内存、端口冲突、离线 UUID、上传和新配置文件写入。 |
| 已有环境升级 | `--check` 只读检测通过。`--upgrade` 备份程序并保留已有账户、MCSManager 和控制台入口。 |
| 浏览器登录和环境检测 | 已使用原 Owner 登录公网 WebUI，读取 Java、内存、磁盘和 Paper 官方版本列表。 |
| EULA 拦截 | 浏览器未勾选 EULA 时拒绝创建。确认后继续。 |
| 新建和配置 | WebUI 创建独立实例，官方 Paper 1.21.11 构建 132 的 `server.jar` 校验通过，写入游戏属性、白名单和 EULA。 |
| 首次启动 | 测试机完成 Java 启动和端口监听。测试环境有约 1.6 GiB 内存，生成世界阶段曾出现管理连接超时。端口监听本身不能确认游戏就绪。 |
| 干净 Ubuntu 安装和发布 | 独立 runner 执行安装、Owner 登录、创建、游戏查询和正常停服。运行结果及截图见 [GitHub Actions](https://github.com/b-h-r123/CraftHome/actions/workflows/release.yml)。 |

实服上的临时测试端口与原游戏端口分开，公网安全组未为临时端口新增规则。浏览器测试核对管理和本机游戏查询流程，公网联机需独立验证。建议以测试记录中明确通过的项目为准。

## 复现

源码编译和浏览器测试命令见 [v0.2 开服指南](v0.2-开服指南.md)。`tests/browser/smoke.cjs` 会创建、启动和停止真实实例，请在隔离环境运行。测试记录只保存结果、页面截图和公开配置，不保存密码或 API Key。
